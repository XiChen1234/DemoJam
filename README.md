# Paws Up! 🐾

一款快节奏的单音轨音乐节奏游戏，只需按两个按键即可享受刺激的视听体验。

## 游戏简介

Paws Up! 是一款快节奏的单音轨音乐节奏游戏，你只需要使用两个按键就能享受刺激的视听体验。游戏特色包括：

- 密集的谱面设计
- 特殊的"快速连打"音符
- 五位性格迥异的 NPC 对应五首特别的音乐
- 可爱的小猫主角！

## 游戏时间

- 大约 20 分钟
- 支持随时暂停
- 自动保存已完成的关卡进度

## 游戏操作

- **短按/长按**：空格键 或 Enter 键
- **快速打击**：在两个按键间快速切换点击

## 剧情简介

一只渴望自由的小猫，从上帝的指尖获得灵魂后，决定逃离伊甸园去寻找属于自己的乐园。

在这段惊险而妙趣横生的旅程中，小猫遇到了几位强大的拦路虎：
- 仁慈的上帝
- 俊美的天使
- 偏执的诺亚
- 残酷的卡戎
- 神秘的潘神

举起爪子吧！击退那些试图控制小猫的手，摆脱一切阻碍猫猫的束缚。帮助小猫在欢快的节奏中奔向更广阔的世界。

## 游戏特色

- **5 位独特角色**：每位角色都有鲜明的个性和专属音乐
- **快节奏玩法**：密集的音符谱面，考验你的反应速度
- **特殊音符**：包含"快速连打"音符，增加游戏挑战性
- **视听体验**：精心设计的音乐与画面配合
